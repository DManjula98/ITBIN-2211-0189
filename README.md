# 📝 To-Do App

A simple and efficient **web-based To-Do application** built with **React** and **Firebase Firestore** to help users manage their daily tasks quickly and effectively.  
This project also demonstrates **modern DevOps practices**, including **CI/CD workflows**, **automated testing**, and **Firebase deployment** using **GitHub Actions**.

---

## 🚀 Features

- Add, edit, and delete tasks easily  
- Real-time synchronization using Firebase Firestore  
- Secure data storage and user authentication  
- Responsive, user-friendly interface  
- Automated CI/CD pipeline with GitHub Actions  
- Continuous integration and deployment to Firebase Hosting  
- Dependency updates and code quality checks  

---

## 🧠 Motivation

In today’s fast-paced environment, people struggle to manage their daily tasks effectively.  
This To-Do App aims to:
- Help users organize and prioritize tasks efficiently  
- Demonstrate practical DevOps principles (CI/CD, automation, and testing)  
- Serve as a learning project for applying software engineering best practices  

---

## 🎯 Project Objectives

- Enable users to add, edit, and delete tasks  
- Provide real-time updates and task synchronization  
- Implement automated testing and deployment workflows  
- Follow modern Git branching, code review, and commit standards  
- Ensure reliability and scalability through CI/CD automation
